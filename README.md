# Менеджер особистих фінансів

Консольна програма для обліку доходів і витрат. Транзакції зберігаються в пам’яті протягом поточного сеансу роботи.

## Можливості

- Додавання доходу або витрати з категорією та описом.
- Перегляд усіх транзакцій у таблиці.
- Підрахунок загального доходу, витрат і балансу.
- Пошук за категорією без урахування регістру літер.
- Видалення транзакції за ID через пункт 8.

Сума має бути додатним скінченним числом. Для дробової частини можна вводити кому або крапку. Для грошових розрахунків використовується `Decimal`. Кожна транзакція має унікальний ID серед записів поточного списку.

## Структура

| Файл | Призначення |
|---|---|
| `main.py` | Меню та взаємодія з користувачем |
| `transactions.py` | Додавання, перегляд і видалення транзакцій |
| `statistics.py` | Суми, баланс і фільтрація |
| `README.md` | Запуск, приклади та пояснення історії Git |
| `.gitignore` | Правила ігнорування локальних і тимчасових файлів |
| `.git/` | Історія комітів, гілки й теги в локальній копії |

## Запуск

Потрібен Python 3.10 або новіший. У терміналі відкрийте папку `finance_manager` і запустіть програму.

```bash
python3 main.py
```

## Приклад

1. Виберіть **1**. Введіть суму `15000`, категорію `Salary` і опис `Monthly salary`.
2. Виберіть **2**. Введіть суму `2500`, категорію `Food` і опис `Groceries`.
3. Виберіть **3**, щоб переглянути обидві транзакції.

```text
ID | TYPE    | AMOUNT | CATEGORY | DESCRIPTION
---------------------------------------------
1  | income  | 15000  | Salary   | Monthly salary
2  | expense | 2500   | Food     | Groceries
```

Пункт **4** покаже дохід `15000`, пункт **5** покаже витрати `2500`, а пункт **6** покаже баланс `12500`. У пункті **7** введіть `food`, щоб побачити витрату на продукти. У пункті **8** введіть ID `2`, щоб видалити її. Після видалення баланс дорівнюватиме `15000`. Пункт **0** завершує роботу.

## Історія Git

Репозиторій містить 18 комітів і п’ять гілок. Три коміти у `feature/transactions` додають створення, перегляд та видалення. Чотири коміти у `feature/statistics` додають доходи, витрати, баланс і фільтр. Обидві гілки об’єднані з `main` через `git merge --no-ff`, тому в графі видно окремі коміти злиття.

Найновіший коміт має повідомлення `Document finance manager and Git workflow`. На нього вказує анотований тег `v1.0.0`.

```bash
git log --oneline
git log --oneline --graph --all
git rev-list --count --all
git branch --merged main
git status
git show v1.0.0 --no-patch
```

## Додаткові вправи

- **Конфлікт злиття.** Гілки `feature/developer-a` і `feature/developer-b` незалежно змінили перший рядок `main.py`. Після злиття першої гілки Git позначив `main.py` як `UU` під час злиття другої, бо обидві версії змінювали один і той самий рядок. Для розв’язання конфлікту обидва формулювання поєднано в одному описі, а маркери конфлікту прибрано. Результат зафіксовано в коміті `Resolve menu documentation merge conflict`.
- **Тимчасове збереження.** Після додавання коментаря до `main.py` команда `git stash` тимчасово зберегла зміну. `git status` показав чисту робочу директорію. `git stash pop` повернула коментар, і `git diff` підтвердив його відновлення. Після перевірки тимчасовий коментар прибрано.
- **Скасування коміту.** Коміт `Add temporary change for revert exercise` додав тестовий коментар. `git revert HEAD` створив новий коміт зі зворотною зміною. Обидва коміти видно в історії, оскільки revert зберігає початковий коміт і записує скасування окремо.

## Публікація на GitHub

Створіть порожній репозиторій `finance_manager` на GitHub. Залиште поля ініціалізації README, ліцензії та .gitignore вимкненими. У терміналі в папці розпакованого проєкту замініть `USERNAME` на свій логін.

```bash
git remote add origin https://github.com/USERNAME/finance_manager.git
git push -u origin main
git push origin --all
git push origin v1.0.0
```

Відкрийте сторінку репозиторію та перевірте файли, коміти, гілки й тег. Для здачі надішліть викладачу посилання на репозиторій.

[Інструкція GitHub для публікації локального репозиторію](https://docs.github.com/en/migrations/importing-source-code/using-the-command-line-to-import-source-code/adding-locally-hosted-code-to-github)
